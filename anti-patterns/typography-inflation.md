# Typography inflation

Supporting material for [`philosophy.md`](../philosophy/philosophy.md) §17 (Typography Inflation) and §8.6 (Hierarchy). It adds depth, not rules.

**Core question (§17):** does the visual hierarchy represent actual importance?

## Recognising it

- Very large headings on pages whose content is ordinary or task-focused.
- Metric numbers rendered huge regardless of how much they matter.
- Size is the only hierarchy tool; weight, colour, spacing, and position are flat.
- Important content pushed below the fold by display type.

## Why it happens

Large type creates drama quickly and looks confident in screenshots. It is a single, easy lever for "hierarchy", so it gets pulled for everything.

## Why it matters

- **Hierarchy.** When size carries all the emphasis, several large items compete and the real priority is unclear (§8.6).
- **Efficiency.** Oversized type consumes space that the task needs, especially at narrow widths.
- **Semantic honesty.** Size claims importance; unimportant content in large type misleads (§8.11).
- **Adaptability.** Very large type breaks first with localisation, long content, and zoom.

## When it is not a problem

- Editorial, marketing, and brand moments where large type is the expression (§8.15).
- A single number that genuinely is the point of the screen, such as a balance or a countdown.
- Display type used sparingly as a deliberate focal point.

## Diagnosing

- What is the most important content on the screen, and is it the largest or most emphasised?
- How many different type sizes are in use, and does each correspond to a role?
- Does the hierarchy still read if sizes are equalised and only weight, colour, and spacing remain?
- What happens with long titles, translations, and 200% text size?

## Repair

1. Size headings by their role in the page's structure, from the existing type scale.
2. Build hierarchy with weight, colour role, spacing, and position as well as size.
3. Quiet secondary text and labels instead of enlarging primary text.
4. Reserve display sizes for the few moments that deserve them.

## Overcorrection

Flattening all type to similar sizes produces a page with no entry point. Scale remains an important tool; it should just correspond to importance.
