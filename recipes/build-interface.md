# Recipe: Build interface

End-to-end workflow for creating a new interface with Plim reasoning.

The reasoning is defined in one place: [`skills/plim-design/SKILL.md`](../skills/plim-design/SKILL.md). Use its decision model, and when there is no mature system to build on, its section "When there is no system to preserve", which covers deriving foundations, choosing density, and deciding how much structure to build. This recipe does not restate them.
