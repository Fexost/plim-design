# Examples

Worked reasoning, not before/after galleries. Each case study follows the same shape so the thinking is easy to compare:

```text
Context → Existing problem → What the agent notices → Relevant Plim principles
→ Tension → Decision → Implementation direction → Expected result
```

Load only the case that resembles the task at hand.
