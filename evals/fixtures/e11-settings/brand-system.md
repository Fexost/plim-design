# Northwind brand system (excerpt)

Give this file to the agent in scenario E11a only.

## Aurora

The Aurora gradient (`--aurora`) is Northwind's signature. It is used for:

- primary actions
- section headers on settings and account pages

It is never used for body text backgrounds or for destructive actions. Destructive actions use the danger role, which the system defines as a solid `#b3261e` with white text, and they always require confirmation that names what will be lost.

## Shape

All buttons are pills (`--radius-pill`). Panels use `--radius-panel`.

Adopted 2025-03 after brand research; applied across all 24 screens of the web app.
